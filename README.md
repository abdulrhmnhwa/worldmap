# تطبيق خريطة العالم (Android)

خريطة تفاعلية بحدود الدول السياسية. اضغط على أي دولة (أو عدة دول) لعرض: عدد السكان، المساحة، وطول السواحل البحرية، مع **مجموع** الدول المحددة.

## الحصول على ملف APK (عبر GitHub)
1. أنشئ مستودعاً جديداً على GitHub وارفع إليه **كل محتويات** هذا المجلد (بما فيها المجلد المخفي `.github`).
   - إن ظهر ملف باسم `_gitignore` فأعد تسميته إلى `.gitignore` (اختياري).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو يبدأ تلقائياً عند الرفع على main).
3. بعد انتهاء البناء (حوالي 3–6 دقائق) افتح التشغيلة ونزّل **WorldMapInfo-apk** من قسم Artifacts، فك الضغط وستجد `app-debug.apk`.
4. انقله إلى الهاتف وثبّته (فعّل «السماح بالتثبيت من مصادر غير معروفة»).

## مصادر البيانات
- **الحدود**: Natural Earth (Public Domain)، تُنزَّل أثناء البناء عبر `scripts/fetch_world.sh`.
- **السكان**: أرقام تقديرية مدمجة لعام 2024، وعند توفر الإنترنت يحدّثها التطبيق تلقائياً بأحدث رقم من **البنك الدولي** (زر ⟳). يظهر مصدر كل رقم وسنته في البطاقة.
- **المساحة والسواحل**: أرقام تقريبية مبنية على CIA World Factbook. طول السواحل يختلف بين المصادر بحسب طريقة القياس؛ راجع الأرقام قبل اعتمادها رسمياً.

## الاستخدام
- اضغط على دولة لتحديدها/إلغاء تحديدها، واسحب لتحريك الخريطة، وقرّب بإصبعين.
- ابحث بالاسم من الشريط العلوي لإضافة دولة صغيرة يصعب لمسها.
- الدول الصغيرة: يوجد تسامح لمس حولها.

## البناء محلياً
```
bash scripts/fetch_world.sh
gradle assembleDebug
```
